# DJango

## Ver que tiene descargado
pip list 

- pip install virtualenv

## Crear entorno: 

- virtualenv entorno

#### Si no funciona
- python -m virtualenv entorno

## Activarlo
- entorno\Scripts\activate

## Instalar DJango
- entorno\Scripts\activate

## Crear el proyecto de DJango
- django-admin startproject backend

Esto va a crear una carpeta llamada backend, esto nos permitira trabajar en el proyecto para programar y crear las apis



## HOME
Se puede ver como si fuera una api, En este caso home solo lo usaremos como ruta principal
- django-admin startapp home
